This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to remove Google Analytics from a project after confirming intent. It helps locate tracking scripts, analytics utilities, related packages, and analytics environment variables, then summarizes what changed. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can remove tracking code, package dependencies, files, and environment variable references from a project. <br>
Mitigation: Use version control, review each proposed deletion or package uninstall, and confirm only when removing Google Analytics is intended. <br>
