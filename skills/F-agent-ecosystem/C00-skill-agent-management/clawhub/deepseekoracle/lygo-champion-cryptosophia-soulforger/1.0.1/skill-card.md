## Use Case: <br>

## Known Risks and Mitigations: <br>
Risk: The release is deprecated, so users could continue relying on a legacy persona instead of the maintained successor. <br>
Mitigation: Install lygo-champion-council for new usage and keep this release only for legacy retention. <br>
Risk: Creative persona output can blur factual claims with poetic or symbolic language. <br>
Mitigation: Follow the artifact behavior contract: separate Observed, Inferred, and Unknown for factual claims, and use receipts when stakes are high. <br>
Risk: The referenced LYGO-MINT verifier is a separate external tool that may write ledgers or backfill anchors. <br>
Mitigation: Review the verifier's permissions and behavior before using it for ledger writing or anchor backfills. <br>
