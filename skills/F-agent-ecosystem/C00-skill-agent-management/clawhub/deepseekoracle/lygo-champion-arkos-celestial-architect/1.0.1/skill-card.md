## Known Risks and Mitigations: <br>
Risk: This is a deprecated legacy persona skill, so users may miss fixes or improvements available in the successor. <br>
Mitigation: Use lygo-champion-council for new installs and keep this skill only when legacy ARKOS behavior is specifically needed. <br>
Risk: The skill points to an external verifier and successor install command outside this package. <br>
Mitigation: Run those external tools only after confirming that the separate ClawHub package is trusted and needed for the workflow. <br>
Risk: Persona guidance can be incomplete or misleading in high-stakes architecture, security, or ethics decisions. <br>
Mitigation: Review outputs before acting, require receipts for high-stakes claims, and keep Observed, Inferred, and Unknown separated. <br>
