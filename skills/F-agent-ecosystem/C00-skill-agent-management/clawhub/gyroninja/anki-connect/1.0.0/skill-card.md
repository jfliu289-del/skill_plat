## Description: <br>
Interact with Anki flashcard decks via the AnkiConnect REST API to create, update, search, and manage cards, decks, notes, and models. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[gyroninja](https://clawhub.ai/user/gyroninja) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and Anki users use this skill to let an agent manage local Anki flashcard content through AnkiConnect when Anki is running with the AnkiConnect plugin installed. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can support changes to local Anki cards, decks, notes, and models, including bulk edits. <br>
Mitigation: Review proposed Anki changes before approval, especially bulk edits or model changes. <br>
Risk: The skill depends on a local AnkiConnect installation. <br>
Mitigation: Install AnkiConnect from a trusted source and use the skill only when local Anki access is intended. <br>
