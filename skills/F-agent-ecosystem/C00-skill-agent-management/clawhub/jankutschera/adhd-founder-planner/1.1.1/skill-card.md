## Description: <br>
Provides an ADHD-friendly bullet journal planning workflow with daily intent setting, rapid logging, energy-based swim lanes, task migration, reflection, and dopamine rewards. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[jankutschera](https://clawhub.ai/user/jankutschera) <br>

### License/Terms of Use: <br>
MIT <br>


## Use Case: <br>
External users and founders use this skill to plan a day, capture tasks, choose work by current energy, reflect on progress, and carry unfinished work forward without treating migration as failure. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Planner notes may contain personal or sensitive information because the workflow creates and updates local markdown files. <br>
Mitigation: Review the planner destination folder before use and avoid recording information that should not be stored in local notes. <br>
