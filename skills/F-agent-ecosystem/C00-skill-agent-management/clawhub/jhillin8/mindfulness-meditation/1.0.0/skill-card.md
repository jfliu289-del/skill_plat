## Description: <br>
Build a meditation practice with guided sessions, streaks, and mindfulness reminders. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[jhillin8](https://clawhub.ai/user/jhillin8) <br>

### License/Terms of Use: <br>


## Use Case: <br>
External users use this skill to start guided meditation sessions, take quick mindfulness pauses, track streaks and session history, and configure reminders for a consistent practice. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Meditation notes, reminders, and exported logs may contain private wellness data. <br>
Mitigation: Keep logs local, avoid sharing exports from shared or synced devices, and review notes before copying them elsewhere. <br>
Risk: Broad meditation-related prompts could start the skill when the user did not intend a meditation flow. <br>
Mitigation: Use explicit meditation prompts before starting guided sessions, reminders, or log review. <br>
