## Description: <br>
Create documentation optimized for AI agent consumption. Use when writing SKILL.md files, README files, API docs, or any documentation that will be read by LLMs in context windows. Helps structure content for RAG retrieval, token efficiency, and the Hybrid Context Hierarchy. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[tylervovan](https://clawhub.ai/user/tylervovan) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and technical documentation authors use this skill to structure AGENTS.md, SKILL.md, README, API, and llms.txt documentation so AI agents can retrieve and follow project guidance efficiently. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated documentation or CI snippets could add incorrect guidance to a project if accepted without review. <br>
Mitigation: Review generated AGENTS.md, SKILL.md, llms.txt, README, and CI snippets before committing them. <br>
Risk: Security examples in documentation could be mistaken for operational instructions by future agents. <br>
Mitigation: Keep security examples clearly labeled as warnings, risks, or mitigations. <br>
