## Known Risks and Mitigations: <br>
Risk: Prompts, brand details, or attached media may be sent to CellCog's external service. <br>
Mitigation: Use the skill only when CellCog's terms and data handling are acceptable, and avoid confidential or regulated data unless approved. <br>
Risk: Video generation can consume credits without producing a usable result. <br>
Mitigation: Start with small tests, monitor credit usage, and review generated media before publishing. <br>
Risk: The skill depends on an API key and Python environment. <br>
Mitigation: Use a scoped or dedicated API key when available and confirm Python 3 and CELLCOG_API_KEY are configured before use. <br>
