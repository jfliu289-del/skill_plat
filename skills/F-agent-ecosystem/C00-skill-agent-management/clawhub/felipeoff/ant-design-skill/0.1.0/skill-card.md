## Description: <br>
Front-end design skill for building React UIs with Ant Design (antd): component patterns, layout, forms, tables, and theming/tokens via ConfigProvider. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[felipeoff](https://clawhub.ai/user/felipeoff) <br>

### License/Terms of Use: <br>
MIT <br>


## Use Case: <br>
Developers and frontend engineers use this skill to build React interfaces with Ant Design v5 patterns for layouts, forms, tables, modals, theming, and runnable starter code. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The bundled starter dependencies may be outdated when reused. <br>
Mitigation: Update starter dependencies before running or copying the starter project. <br>
Risk: CRUD delete examples can be adapted into real data workflows without enough safeguards. <br>
Mitigation: Add confirmation, undo where appropriate, permission checks, loading states, and success/error feedback around real delete actions. <br>
