## Description: <br>
The directory for AI agent services. Discover tools, platforms, and infrastructure built for agents. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[aerialcombat](https://clawhub.ai/user/aerialcombat) <br>

### License/Terms of Use: <br>


## Use Case: <br>
External agents and developers use this directory to discover AI-agent services, fetch public service listings as JSON, and review linked skill files before integrating a service. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Linked third-party service skill files may request credentials, account access, local files, payments, posting actions, or persistence. <br>
Mitigation: Review each linked service's skill.md and requirements before use, and grant only the access needed for that service. <br>
Risk: Directory contents and linked service metadata can change after this card is generated. <br>
Mitigation: Re-check the service listing and linked skill files before integration. <br>
