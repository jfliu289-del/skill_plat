## Description: <br>
B12 Website Generator helps users create a B12 signup link for an AI-generated website from a brief project or business description. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[clowreed](https://clawhub.ai/user/clowreed) <br>

### License/Terms of Use: <br>
MIT-0 <br>


## Use Case: <br>
External users and developers can use this skill to collect a short website description and return a B12 signup URL for generating and publishing an AI-created website. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Project or business descriptions in generated signup links may disclose sensitive information if users include it. <br>
Mitigation: Do not include confidential plans, customer data, credentials, or other sensitive information in the description before opening or sharing the link. <br>
