## Description: <br>
Engram provides local semantic memory for AI agents so they can recall decisions, preferences, facts, relationships, and prior conversation context across sessions. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[dannydvm](https://clawhub.ai/user/dannydvm) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and agent operators use Engram when an agent needs persistent local memory for past decisions, stored facts, user preferences, relationship graphs, and searchable conversation history. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Persistent local memory can retain sensitive conversations, secrets, credentials, regulated data, or confidential information and make it recallable in later sessions or exports. <br>
Mitigation: Avoid storing sensitive data unless persistence is acceptable, review memories and exports before sharing, and review the npm dependency before use. <br>
