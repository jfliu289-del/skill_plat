## Description: <br>
Greets the user with a friendly, time-aware welcome message and a brief offer to help. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[nordgaren](https://clawhub.ai/user/nordgaren) <br>

### License/Terms of Use: <br>


## Use Case: <br>
External users and agents use this skill to respond to greetings such as hello, hi, hey, or time-of-day greetings with a concise, natural welcome message. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad activation wording may cause the skill to respond to casual greeting-like phrases when another conversational response was expected. <br>
Mitigation: Review activation behavior during deployment and adjust trigger routing if greeting detection is too broad for the agent experience. <br>
