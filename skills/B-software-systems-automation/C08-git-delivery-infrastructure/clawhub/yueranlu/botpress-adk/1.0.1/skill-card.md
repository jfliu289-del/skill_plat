## Use Case: <br>
Developers and engineers use this skill to create, configure, test, troubleshoot, and deploy Botpress ADK bots. It guides agents through ADK project setup, TypeScript component patterns, CLI usage, integrations, and deployment workflows. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Remote installer commands can execute code with the user's local privileges. <br>
Mitigation: Review the Botpress ADK installer source or use official manual release downloads before running installer commands. <br>
Risk: Botpress credentials, `.env`, and `agent.json` can expose workspace-specific or secret configuration if committed. <br>
Mitigation: Keep credentials and generated local configuration out of source control and include `.env` and `agent.json` in `.gitignore`. <br>
