## Known Risks and Mitigations: <br>
Risk: Some referenced Git commands can discard local work, delete branches or tags, change remotes, or affect collaborators when pushed. <br>
Mitigation: Before running reset, clean, force-push, delete, or remote-changing commands, verify the repository, branch, and remote target. <br>
