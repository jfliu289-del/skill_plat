## Use Case: <br>
Developers, crypto analysts, and agent builders use this skill to screen token symbols or contract addresses for rug-pull, copycat, holder concentration, liquidity, and contract-risk signals. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Token symbols or contract addresses are sent to the configured PRISM API. <br>
Mitigation: Install only when that API disclosure is acceptable for the intended workflow. <br>
Risk: Scanner output can be mistaken for financial advice or a complete audit. <br>
Mitigation: Use results as a screening signal and keep independent review in the decision process. <br>
Risk: Broad trigger wording can cause unintended scans. <br>
Mitigation: Prefer explicit invocation wording when configuring an agent to use the skill. <br>
