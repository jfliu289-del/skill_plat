## Known Risks and Mitigations: <br>
Risk: Example commands may expose secrets when tokens, passwords, API keys, or cookies are placed directly in command lines or URLs. <br>
Mitigation: Review and adapt commands before running them, and avoid putting real secrets directly in command lines or URLs. <br>
Risk: Download examples can overwrite files or save content to unintended locations if paths are not chosen carefully. <br>
Mitigation: Save downloads to explicit safe paths and inspect filenames before execution. <br>
Risk: The skill includes an SSL/TLS example using -k/--insecure, which disables certificate verification. <br>
Mitigation: Do not use -k/--insecure with sensitive traffic. <br>
