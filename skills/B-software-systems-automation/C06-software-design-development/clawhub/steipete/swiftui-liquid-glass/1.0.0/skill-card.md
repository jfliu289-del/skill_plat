## Known Risks and Mitigations: <br>
Risk: Generated SwiftUI code may use outdated or incorrect iOS 26 Liquid Glass API details. <br>
Mitigation: Review generated code against current Apple documentation and verify availability checks before use. <br>
Risk: The skill may activate for broad Apple design requests where Liquid Glass guidance is not appropriate. <br>
Mitigation: Confirm that the requested task is specifically about adopting, improving, or reviewing Liquid Glass before applying the guidance. <br>
Risk: Liquid Glass usage can exclude earlier iOS versions if fallback UI is omitted. <br>
Mitigation: Require #available(iOS 26, *) checks and non-glass fallback visuals for earlier iOS versions. <br>
