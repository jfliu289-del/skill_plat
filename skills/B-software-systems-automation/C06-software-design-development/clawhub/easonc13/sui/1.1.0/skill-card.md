## Description: <br>
Answer questions about Sui blockchain ecosystem, concepts, tokenomics, validators, staking, and general knowledge. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[easonc13](https://clawhub.ai/user/easonc13) <br>

### License/Terms of Use: <br>
MIT <br>


## Use Case: <br>
Developers, operators, and users use this skill to answer general Sui blockchain questions, compare Sui with other chains, and find Sui ecosystem or tokenomics guidance. It routes Move programming questions to a separate Sui Move skill. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Setup downloads the current Sui documentation from GitHub, so local reference content may change over time. <br>
Mitigation: Review or pin the documentation checkout before running setup.sh when reproducible reference content is required. <br>
