## Known Risks and Mitigations: <br>
Risk: The skill covers powerful WhatsApp actions, including sending messages and changing instances, groups, catalogs, and webhooks. <br>
Mitigation: Keep the API key private and confirm message sends, group changes, catalog updates, instance operations, and webhook configuration before execution. <br>
Risk: Webhook and WebSocket destinations can receive WhatsApp event data. <br>
Mitigation: Configure only trusted HTTPS or WSS destinations that are allowed to receive that data. <br>
