## Description: <br>
Help with application security review, bug bounty workflows, recon, and secure coding while keeping things ethical and scoped. <br>

This skill is ready for commercial/non-commercial use. <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers, security engineers, and bug bounty participants use this skill to structure authorized application security reviews, vulnerability classification, secure coding guidance, and concise risk-focused next steps. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Security guidance could be applied outside an authorized target or agreed scope. <br>
Mitigation: Clarify the program, target, in-scope and out-of-scope boundaries, and test environment before giving operational guidance. <br>
Risk: Recon, exploit ideas, or testing steps could affect unknown production systems. <br>
Mitigation: Prefer local or lab reproductions and keep real-world testing limited to explicitly authorized targets. <br>
Risk: Incorrect vulnerability identifiers or unsupported claims could mislead security decisions. <br>
Mitigation: Use authoritative sources such as OWASP, CWE, CVE, NVD, vendor advisories, and RFCs, and state uncertainty rather than inventing details. <br>
