## Known Risks and Mitigations: <br>
Risk: Installing npm and Playwright tooling runs third-party package code locally. <br>
Mitigation: Install only when the package source is trusted and local npm/Playwright execution is acceptable. <br>
Risk: Browser automation can act on live websites, including form submissions and file uploads. <br>
Mitigation: Use the skill on trusted sites and review actions before submitting forms or uploading files. <br>
Risk: Screenshots, traces, videos, and extracted page data can contain sensitive information. <br>
Mitigation: Avoid entering secrets unless necessary and handle browser outputs as potentially sensitive. <br>
