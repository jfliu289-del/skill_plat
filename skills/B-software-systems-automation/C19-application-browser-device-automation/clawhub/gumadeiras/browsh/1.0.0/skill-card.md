## Known Risks and Mitigations: <br>
Risk: Untrusted Browsh or Firefox binaries on PATH could expose browsing activity or run unexpected browser behavior. <br>
Mitigation: Install Browsh and Firefox from trusted sources and confirm PATH entries before using the skill. <br>
