## Description: <br>
Conducts rigorous, adversarial code reviews that identify security holes, lazy patterns, edge case failures, bad practices, and code quality issues. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ziad-hsn](https://clawhub.ai/user/ziad-hsn) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and engineering teams use this skill to receive strict, structured review feedback on code snippets, pull requests, or code changes. It helps surface security, correctness, maintainability, performance, accessibility, and test coverage concerns with severity-based recommendations. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Strict review feedback may be too blunt for publication if posted directly to a pull request. <br>
Mitigation: Review the generated feedback before publishing it, and only post PR comments when that outcome is intended. <br>
Risk: Review suggestions may be incomplete or incorrect when the skill receives only partial code context. <br>
Mitigation: Treat findings as reviewer guidance and verify them against the full codebase before applying changes. <br>
