## Use Case: <br>
Developers and engineers use this skill to inspect Sui Move coverage, identify untested functions, assertions, and branches, generate missing tests, and summarize security issues discovered while testing. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill may generate or change local Sui Move tests and its artifact workflow asks the agent to commit test improvements automatically. <br>
Mitigation: Run it on a branch, review generated reports and diffs, and only allow commits after explicit approval. <br>
