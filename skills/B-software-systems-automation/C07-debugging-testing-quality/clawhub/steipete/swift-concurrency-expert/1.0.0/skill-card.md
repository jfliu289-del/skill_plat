## Description: <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and engineers use this skill to review Swift 6.2+ concurrency usage, triage compiler diagnostics, and propose focused fixes for actor isolation, Sendable safety, task lifetimes, and SwiftUI main-actor behavior. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Concurrency remediation can change actor isolation, Sendable conformance, task lifetimes, or main-thread behavior. <br>
Mitigation: Review proposed code changes before applying them and confirm they preserve intended runtime behavior. <br>
