## Description: <br>
Refactor and review SwiftUI view files for consistent structure, dependency injection, and Observation usage. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers working on SwiftUI code use this skill to refactor views for consistent declaration order, MV-first state handling, dependency injection, and Observation-safe view model initialization while preserving behavior. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: A SwiftUI refactor could unintentionally alter data flow, state ownership, or app behavior. <br>
Mitigation: Review proposed code changes normally, especially changes around dependencies, @State, @Observable, task/onChange, and view model initialization. <br>
