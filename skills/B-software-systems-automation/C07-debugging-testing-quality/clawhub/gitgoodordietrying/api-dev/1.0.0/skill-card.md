## Known Risks and Mitigations: <br>
Risk: Examples include mutating HTTP methods, uploads, token-bearing requests, response saving, and local process commands that could affect real services or expose secrets if copied without review. <br>
Mitigation: Run examples against localhost, mocks, or test systems by default; review DELETE, PUT, PATCH, upload, kill, and file-saving commands; use scoped test tokens and keep production secrets out of shell history, logs, and shared output. <br>
