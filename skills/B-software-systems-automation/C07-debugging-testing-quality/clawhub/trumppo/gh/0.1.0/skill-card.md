## Known Risks and Mitigations: <br>
Risk: The skill can propose mutating GitHub operations that affect repositories, pull requests, issues, or releases. <br>
Mitigation: Confirm the repository owner/name, active gh account, and intended action before running mutating gh commands, especially for merges, releases, public repos, or organization-owned projects. <br>
