This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and content moderation teams use this skill to add profanity checks, censorship suggestions, and moderation guidance for user-generated text such as chat messages, comments, and submitted content. <br>

Risk: Package identity or supply-chain mismatch when installing the npm or PyPI package. <br>
Mitigation: Confirm the package is the intended package before installation and pin a known-good version for production use. <br>
Risk: False positives or inappropriate automatic moderation actions can affect users. <br>
Mitigation: Use human review, appeal paths, and workflow checks before fully automatic deletion or warning actions. <br>
