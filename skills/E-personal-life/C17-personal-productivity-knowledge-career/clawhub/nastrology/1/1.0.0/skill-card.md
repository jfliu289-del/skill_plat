## Description: <br>
Second Brain helps agents capture, organize, retrieve, and manage a user's personal knowledge base through Ensue. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[nastrology](https://clawhub.ai/user/nastrology) <br>

### License/Terms of Use: <br>


## Use Case: <br>
External users and developers use this skill to save confirmed knowledge, search existing notes, manage toolbox entries, and maintain structured concepts, patterns, references, notes, and journal entries in Ensue. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Saved notes are durable remote data stored through Ensue. <br>
Mitigation: Review drafts before saving and avoid credentials, private paths, sensitive personal details, and time-sensitive material. <br>
Risk: The skill requires an Ensue API key to call the remote API. <br>
Mitigation: Use a revocable API key where possible and never log or display the key. <br>
