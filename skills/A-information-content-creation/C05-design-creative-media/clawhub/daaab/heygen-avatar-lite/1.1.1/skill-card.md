Global <br>

## Known Risks and Mitigations: <br>
Risk: The guide uses a HeyGen API key for third-party API calls. <br>
Mitigation: Store the API key as a secret, avoid pasting real credentials into shared chats or files, and rotate it if exposed. <br>
Risk: Generated videos may consume paid HeyGen credits or involve affiliate and premium links. <br>
Mitigation: Review HeyGen pricing, terms, and disclosed paid links before running requests or purchasing related offerings. <br>
Risk: Avatar or voice material can be sensitive or non-consensual. <br>
Mitigation: Use only consented, appropriate media and review generated videos before publishing or sharing them. <br>
