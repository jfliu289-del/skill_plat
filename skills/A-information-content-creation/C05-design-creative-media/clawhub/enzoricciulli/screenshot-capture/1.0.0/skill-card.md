## Description: <br>
Process screenshots Enzo shares with comments, save them to a reference library, extract content, categorize entries, set reminders, and log patterns. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[enzoricciulli](https://clawhub.ai/user/enzoricciulli) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Users who collect screenshots use this skill to save commented images into local notes, categorize them as frameworks, AI hacks, or ideas, summarize the captured content, and create a one-week follow-up reminder. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Screenshots may contain passwords, tokens, private messages, financial data, or proprietary material that should not be saved into notes. <br>
Mitigation: Use the skill only on screenshots intended for local capture, and avoid or redact sensitive screenshots before asking the agent to save them. <br>
Risk: The workflow saves screenshot-derived content and creates a one-week reminder by default. <br>
Mitigation: Tell the agent clearly when a screenshot should not be saved or when no reminder should be created. <br>
