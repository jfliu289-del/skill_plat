## Description: <br>
Researches a codebase and creates architectural documentation describing how features or systems work. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[ziad-hsn](https://clawhub.ai/user/ziad-hsn) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers and AI agents use this skill to research a scoped codebase feature or system and produce architecture documentation for onboarding, knowledge transfer, and future maintenance. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Unclear scope can lead to incomplete or misleading architecture documentation. <br>
Mitigation: Define the repository and feature scope clearly, then review the proposed outline and draft before relying on the document. <br>
Risk: The skill can write an architecture document to disk after user confirmation. <br>
Mitigation: Confirm the output path only after reviewing the generated document and deciding that the file should be written there. <br>
