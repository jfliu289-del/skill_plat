## Description: <br>
Create new documentation entities in the docs-first system by routing tasks, definitions, rules, features, social content, and changelog requests to specialized creation workflows. <br>

This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Developers and documentation maintainers use this skill to create structured project documentation with consistent folders, templates, signals, and validation checks. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill can guide agents to create or update multiple documentation files and signal files. <br>
Mitigation: Review generated file paths and diffs before accepting changes, especially when using batch creation examples. <br>
Risk: Generated documentation may include TODO placeholders or incomplete required sections. <br>
Mitigation: Run the documented structure and section checks, then remove placeholders before finalizing the documents. <br>
