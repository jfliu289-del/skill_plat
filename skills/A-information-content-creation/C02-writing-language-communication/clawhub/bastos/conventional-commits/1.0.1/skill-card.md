## Description: <br>
Format commit messages using the Conventional Commits specification for automated tooling, changelog generation, and semantic versioning. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[bastos](https://clawhub.ai/user/bastos) <br>

### License/Terms of Use: <br>
MIT <br>


## Use Case: <br>
Developers and engineers use this skill to draft or check git commit messages against the Conventional Commits format. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Broad trigger wording may activate the skill during general git commit discussions. <br>
Mitigation: Confirm the user wants Conventional Commits-specific guidance before applying the format. <br>
Risk: Commit message guidance can be incorrect or too generic for a repository's release process. <br>
Mitigation: Review proposed commit messages against the repository's contribution and release conventions before committing. <br>
