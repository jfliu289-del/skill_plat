This skill is ready for commercial/non-commercial use. <br>

## Use Case: <br>
Caregivers and assistants use this skill to produce Huckleberry CLI commands for recording sleep, feeding, diaper, and growth events. It is useful when users want terminal-based guidance for logging baby activity data. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: The skill guides use of an unofficial CLI that can access Huckleberry account credentials and baby-tracking records. <br>
Mitigation: Install only trusted packages, prefer interactive login, avoid storing passwords in shared shell profiles or logs, protect the local config file, and review child, unit, timing, and amount values before logging records. <br>
