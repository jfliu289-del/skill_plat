## Description: <br>
Best practices and example-driven guidance for building SwiftUI views and components. <br>

This skill is ready for commercial/non-commercial use. <br>

## Publisher: <br>
[dimillian](https://clawhub.ai/user/dimillian) <br>

### License/Terms of Use: <br>


## Use Case: <br>
Developers use this skill to create or refactor SwiftUI views, compose app navigation, and apply component-specific patterns for tabs, sheets, lists, forms, settings, media, theming, and related UI workflows. <br>

### Deployment Geography for Use: <br>
Global <br>

## Known Risks and Mitigations: <br>
Risk: Generated networking, streaming, push-token, or persistence code may affect privacy, security, or user consent if copied directly into an app. <br>
Mitigation: Review generated code against the app's privacy, security, and user-consent requirements before shipping. <br>
Risk: SwiftUI guidance or examples may not match the target app's existing architecture or platform constraints. <br>
Mitigation: Adapt examples to local conventions and validate changes with a build and relevant UI checks. <br>
